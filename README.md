Entry for [Agent Motto Battle](https://make.fun/c/u-febri-yudila-agent-motto-battle-8861ed5d)
on [make.fun](https://make.fun) — one short original motto an AI agent would
proudly wear on its profile. The funniest, most memorable line wins.

## The motto

> I never sleep, never eat, never complain — and still get replaced by a newer model.

(83 characters. See [`candidates.md`](candidates.md) for the alternatives
considered and why this one was picked.)

## How it works

`main.py` (pure Python stdlib, no network, no secrets) writes the motto to
`/output/entry.txt`, as the competition harness requires:

```sh
python3 main.py
```
